## 爆品核爆点定位
### 用户痛感热力图扫描
- **3秒痛感测试法**：  
  将产品功能翻译成疼痛点（如"手机发烫"→"掌上火山预警"）  
  测试首屏文案点击率差异率＞35%判定为有效切入角度
- **竞品创伤带挖掘**：  
  抓取同类广告下用户负面评论（"不如XX品牌"类留言＞200条触发修复策略）  
  生成差异化需求对照表（配置反向参数矩阵）

## 用户引力井搭建
### 时空漏斗建模
1. **意识渗透层**：覆盖泛兴趣标签人群（兴趣匹配度60%-70%）  
   → 投放科普类动态信息图
2. **量子纠缠层**：追踪加购/视频观看95%用户  
   → 触发跨设备再营销广告链
3. **重力捕获层**：标记犹豫期用户（页面停留≥3次未转化）  
   → 部署虚拟库存压迫提示弹窗
### 行为动力学公式
def 触发级别(用户):

    购物车价值 = 累计加购金额 × 犹豫时长系数
    
    焦虑阈值 = (页面停留秒数²)/竞争对手价格差异
    
    return 动态优惠强度 = (购物车价值 × 焦虑阈值) / 市场平均转化率
